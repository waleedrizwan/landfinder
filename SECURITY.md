# Security

If you find a security problem in landfinder or the site at cheapest-land.pages.dev (for example a way past the
password gate, or a way for a listing to inject script into the page), please report it privately through
[GitHub's private vulnerability reporting](https://github.com/waleedrizwan/landfinder/security/advisories/new)
rather than in a public issue.

Please include the steps to reproduce it. You'll get a reply as soon as possible, and a fix will be credited to you
unless you'd rather it wasn't.
